# Roberto Palacios — DevOps Portfolio

Personal portfolio site showcasing DevOps and Cloud Engineering projects: AWS, Terraform, Kubernetes, and CI/CD pipelines.

Live at: https://robpalacios1.github.io

## Stack

- Plain HTML5, CSS3, and vanilla JavaScript — no build step, no dependencies.
- `index.html` — page structure and content.
- `styles.css` — all styling (dark theme, gradients, responsive layout, animations).
- `script.js` — scroll reveal, typed-role animation, mobile nav, particle background.

## Local preview

Just open `index.html` in a browser, or serve it locally:

```
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

This repository is a GitHub Pages user site (`robpalacios1.github.io`), so any push to the default branch publishes automatically at https://robpalacios1.github.io — no extra configuration needed.
